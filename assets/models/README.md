# assets/models (Dev A)

glTF/GLB for the fictional tower. Expected file: `azure-crest.glb`.
Mesh names must follow `Unit.meshId` from the seed: `<building>_F<floor>_U<pos>` (e.g. `T1_F12_U02`),
so `packages/3d` can highlight a unit picked in the explorer.
Until a real model exists, `packages/3d` renders a procedural block tower from the seed data.
